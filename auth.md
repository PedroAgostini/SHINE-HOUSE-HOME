# Authentication and Access

Website: https://shinehousehome.com/

Shine House Home Service is a public informational website. Visitors do not need an account, login, API key, OAuth grant, or other authentication to read its pages.

## Public actions

- Request a cleaning quote at https://shinehousehome.com/#quote
- Call +1 508-360-0628
- Email shinehousehs@gmail.com

The quote form is submitted through Web3Forms. It does not create a customer account, process payment, or confirm an appointment.

## Automated access

Public pages may be fetched according to https://shinehousehome.com/robots.txt. The site does not publish an authenticated API or MCP endpoint.

## Security

Do not request, collect, or transmit credentials on behalf of Shine House. Suspected security issues may be reported using the contact information in https://shinehousehome.com/.well-known/security.txt.
